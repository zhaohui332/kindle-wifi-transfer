通过 GitHub 从手机传书到 Kindle

🔑 配置 GitHub Token

首次使用需输入 GitHub Token，用于上传电子书。
Token 保存在本地浏览器，不会上传到其他地方。

如何获取？
GitHub → Settings → Developer settings →
Personal access tokens → Tokens (classic)
勾选 repo 权限，生成后粘贴到上方

没有 Token 也可以浏览和下载已有电子书

点击选择或拖拽文件
支持 .mobi .azw .azw3 .pdf .txt .epub
